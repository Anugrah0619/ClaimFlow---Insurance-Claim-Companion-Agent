3. AGENT ARCHITECTURE
- Using LangGraph `create_react_agent`
- LLM: Google Gemini Developer API
- Agent responsibility:
  - Decide whether an uploaded document matches the expected claim task
  - Return structured JSON:
    {
      "accepted": true/false,
      "reason": "short explanation"
    }
- Tool:
  - validate_uploaded_document (basic rule-based fallback)
- UI does NOT make decisions; agent decides task acceptance.
